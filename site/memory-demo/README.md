# DEMO fixture for the Memory and learning page

Invented records that exercise every state the page must handle: a correction, a duplicate, a pending event, a dispute, a negative event, a retracted lesson, a rule change, and the Memory V1.1 lifecycle (selection episodes, a promoted learned lesson under contradiction, a rejected and a provisional candidate, a NO LESSON CANDIDATE check). They are NOT agent history. The build turns them into `memory-demo.json`, which carries `"demo": true` and is shown only behind the page's DEMO switch. They never enter `memory-export.json`.
